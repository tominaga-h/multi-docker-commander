# v2.0.3 リリースノート

`mdc down` 実行時に発生していた PID ファイル残留バグを修正したバグ修正リリース。あわせて、死んだ（既に終了済みの）プロセスのエントリをまとめて掃除できる `mdc proc kill --dead` オプションを追加した。

## バグ修正

- **`mdc down` 時の PID ファイル残留を修正**: `down` がコマンド失敗で途中終了しても、追跡中のバックグラウンドプロセスのクリーンアップが必ず実行されるようにした (#177)

## 主な機能

- **`mdc proc kill --dead`**: 既に終了しているプロセスの PID ファイルエントリのみを一括削除する。実行中のプロセスは対象外 (#191)

## 内部改善

- `down` のクリーンアップ処理を、失敗時でも確実に走る不変条件として整理
- 関連テスト・統合テストを追加

## 対応プラットフォーム

- macOS / Linux (PTY 対応)
- Windows (PTY なしのフォールバック)

## 既知の制限

- `mdc ps` コマンドは `docker` / `docker compose` がインストールされた環境でのみ動作
